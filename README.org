#+TITLE: Convert plain text to InDesign math expressions with ExtendScript
#+AUTHOR: Roger Farrell

* Usage

Select a single line of text in an InDesign text object, then activate
the script. Your selection will be replaced with a minimally formatted
math expression.

*Bind this script to a comfortable key-chord for mouse-free workflows.*

** Example input

#+begin_example
(2 - 3) * 5 = -5
#+end_example

* AI disclaimer

This project started as a hand-coded Guile Scheme
script. Unfortunately, I needed tighter integration with InDesign for
work. I hate working with the InDesign API so I used Claude to convert
my working Guile code into an ExtendScript.
